# Predicción de Resultados del Mundial 2026

Proyecto para predecir y registrar resultados del Mundial de Fútbol 2026.

## Mundial 2026
- **Sede:** Estados Unidos, Canadá y México
- **Fecha:** 11 de junio – 19 de julio de 2026
- **Equipos:** 48 selecciones

## Descripción

Aplicación para gestionar predicciones de partidos, seguimiento de resultados y clasificaciones del Mundial FIFA 2026.
